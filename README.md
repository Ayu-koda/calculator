# 🧮 Basic Calculator

A simple and responsive **Basic Calculator** built using **HTML, CSS, and JavaScript**. This project performs basic arithmetic operations with a clean and user-friendly interface.

## 🚀 Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* 🔄 Clear/Reset functionality
* 📱 Responsive design
* ⚡ Fast and interactive calculations
* 🎨 Simple and clean UI

## 🛠️ Technologies Used

* **HTML5** – Structure of the calculator
* **CSS3** – Styling and responsive layout
* **JavaScript** – Calculator logic and functionality

## 📂 Project Structure

```text
Basic-Calculator/
│
├── index.html
├── style.css
└── script.js
```

## 💻 How to Run

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in any modern web browser.
4. Start performing calculations.

## 🎯 Purpose

This project was created to strengthen my understanding of **HTML, CSS, JavaScript, DOM manipulation, event handling, and basic frontend development**.
